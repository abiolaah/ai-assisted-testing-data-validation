# Human Review Checklist for AI-Generated QA Output

- [ ] Every suggested test maps to a documented requirement or is explicitly labeled an assumption.
- [ ] Generated test data uses realistic formats.
- [ ] Boundary values are independently checked.
- [ ] API field names/types match the actual contract.
- [ ] AI-generated code was reviewed before execution.
- [ ] AI did not introduce unsupported business rules.
- [ ] Sensitive/customer data was not submitted to the AI tool.
- [ ] Final test cases were approved by a human.
